# Desafio de 30 minutos

Esta carpeta marca el inicio de un desafio corto de 30 minutos dentro de `VoxelParty`.

La idea es sincronizar este fork con el repositorio original antes de empezar, para trabajar desde una base limpia y comparable. A partir de ese punto, el objetivo es resolver o avanzar la consigna dentro del tiempo disponible, priorizando decisiones simples, claras y faciles de revisar.

Este archivo tambien permite que la carpeta exista en Git sin depender de un `.gitkeep`.
